# Changelog

## v1.0.0 — 2026-09-10

- Establishes the first portfolio release for the multi-tenant inventory API.
- Documents RBAC, tenant isolation, transactional inventory, migrations and integration tests.
- Publishes a guided public demonstration.

### Running the project

Follow the README to configure PostgreSQL, environment variables and Docker or local execution.

### Known limitations

- The public walkthrough is demonstrative and does not host a production tenant.
- Production deployments need their own secrets, monitoring and backup strategy.
